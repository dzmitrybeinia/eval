### Les Variables

Une variable est un conteneur utilisé pour stocker des informations dans un programme. Ces informations peuvent être de différents types, comme des nombres ou du texte. Les variables permettent de manipuler et de conserver des données tout au long de l'exécution d'un programme.

**Exemple :**
```python
age = 13
nom = "Alice"
```
Dans cet exemple, `age` est une variable qui contient le nombre 13, et `nom` est une variable qui contient le texte "Alice".

### Les Boucles

Une boucle est une structure qui permet de répéter une série d'instructions plusieurs fois. Cela évite de devoir réécrire le même code plusieurs fois et rend le programme plus efficace.

**Exemple :**
```python
for i in range(5):
    print("Bonjour !")
```
Dans cet exemple, la boucle imprime "Bonjour !" cinq fois.

### Les Conditionnels

Les conditionnels sont des instructions qui permettent de prendre des décisions dans un programme en fonction de certaines conditions. Ils utilisent des mots-clés comme "if", "else if" et "else" pour déterminer le chemin à suivre selon les données disponibles.

**Exemple :**
```python
if age > 18:
    print("Vous êtes majeur.")
else:
    print("Vous êtes mineur.")
```
Ici, le programme vérifie si la variable `age` est supérieure à 18 pour déterminer le message à afficher.
