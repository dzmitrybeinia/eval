### Pythonの変数

**変数とは:**
変数はプログラム内で値を格納する名前のことです。変数を使用することで、データを再利用したり操作したりすることが容易になります。

Pythonでは、変数に格納するデータの型を事前に指定する必要はありません。

**構文:**
```python
変数名 = 値
```

**例:**
```python
年齢 = 14
名前 = "アリス"
学生ですか = True
```

#### **Themes:**
- 変数の定義
- 変数の使い方

## YesNo

**Statement:** Pythonでは、変数には値を格納することしかできません。.

**Answer:** False

**Feedback:**
Pythonでは、変数が値を格納することだけでなく、条件やループなどのコードの中で処理を変えるためにも使用されます。.

### Pythonのデータ型

Pythonにはいくつかの組み込みデータ型があります。主なものを以下に示します：

- **整数型 (int):** 整数値 (例: 10, -3)。
- **浮動小数点型 (float):** 小数を含む数値 (例: 3.14, -0.5)。
- **文字列型 (str):** 引用符で囲まれたテキスト (例: "hello", 'world')。
- **ブール型 (bool):** 真または偽の値。

**例:**
```python
x = 10          # 整数型
y = 3.14        # 浮動小数点型
text = "Python" # 文字列型
flag = True     # ブール型
```

#### **Themes:**
- データ型の種類

### Pythonの基本操作

Pythonでは、データを使ってさまざまな操作を行うことができます。

### **算術操作:**
- 加算 (`+`): 数値を結合。
- 減算 (`-`): 差を求める。
- 乗算 (`*`): 積を求める。
- 除算 (`/`): 数値を割る。

**例:**
```python
a = 5
b = 3
和 = a + b        # 8
差 = a - b        # 2
積 = a * b        # 15
商 = a / b        # 1.6667
```

### **文字列操作:**
- **連結:** `+` を使って文字列を結合。
- **繰り返し:** `*` を使って文字列を繰り返し。

**例:**
```python
挨拶 = "こんにちは"
名前 = "アリス"
メッセージ = 挨拶 + ", " + 名前  # "こんにちは, アリス"
繰り返し = 挨拶 * 3             # "こんにちはこんにちはこんにちは"
```
