### ¿Qué es un Algoritmo?

Un **algoritmo** es un conjunto de pasos organizados que se siguen para resolver un problema o realizar una tarea específica.

### Ejemplo práctico:
Imagina que quieres encontrar el número más grande en una lista de números:
1. Comienza con el primer número como el "mayor".
2. Compara el siguiente número de la lista con el "mayor" actual.
3. Si el siguiente número es más grande, actualiza el "mayor".
4. Repite estos pasos hasta revisar todos los números.

Esta definición es crucial para entender cómo los algoritmos funcionan en la programación, donde cada paso es una instrucción que contribuye al resultado general.

### ¿Qué son las Variables?

Una **variable** es un espacio en la memoria de una computadora donde se guarda información que puede cambiar mientras el programa se ejecuta.

### Ejemplo práctico:
En un videojuego, podrías usar una variable llamada `monedasJugador` para rastrear cuántas monedas ha recogido el jugador:
- Inicio del juego: `monedasJugador = 0`
- Cuando el jugador recoge una moneda: `monedasJugador = monedasJugador + 1`

Las variables permiten almacenar y actualizar datos de manera dinámica.

#### **Themes:**
- definición de variables

### ¿Qué son los Bucles Simples?

Un **bucle** es una estructura en programación que permite repetir un conjunto de instrucciones varias veces.

### Ejemplo práctico:
Supongamos que quieres imprimir los números del 1 al 10 en la pantalla. En lugar de escribir 10 líneas de código, puedes usar un bucle:

#### Ejemplo en pseudocódigo:
```
PARA número = 1 HASTA 10
    IMPRIMIR número
FIN PARA
```
Este bucle repite las instrucciones hasta alcanzar el número 10.

- definición de bucles simples

**Answer:** False

Sin variables, sería extremadamente limitado la capacidad de un programa para manejar información dinámica y adaptarse a diferentes situaciones.

### Conectando la Programación con la Resolución de Problemas

Los conceptos de programación como algoritmos, variables y bucles están estrechamente relacionados con el proceso de diseño ingenieril. Al resolver problemas, los ingenieros definen:
- **Criterios:** Lo que la solución debe lograr.
- **Restricciones:** Limitaciones como tiempo, recursos o materiales.

### Ejemplo práctico:
Diseñando un programa para calcular el costo total de compras:
- **Criterios:** Sumar correctamente los precios de los artículos.
- **Restricciones:** Funcionar para cualquier número de artículos y calcular rápidamente.
- **Solución:** Usar variables para almacenar precios, un algoritmo para sumar y un bucle para procesar cada artículo.
