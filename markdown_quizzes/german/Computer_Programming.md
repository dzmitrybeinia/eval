### Verständnis von Variablen

Eine *Variable* ist ein Weg, Informationen in einem Programm zu speichern. Man kann sie sich wie einen Container vorstellen, der Daten hält. Variablen haben Namen, damit Programmierer die gespeicherten Daten leicht referenzieren können. In Python muss der Typ einer Variablen nicht deklariert werden; er wird durch den Wert bestimmt, den man ihr zuweist.

**Beispiel:**
```python
name = "Alice"
age = 15
is_student = True
```
Hier:
- `name` speichert den Text "Alice".
- `age` speichert die Zahl `15`.
- `is_student` speichert einen booleschen Wert `True`.

### Häufige Datentypen in Python

Python bietet mehrere eingebaute Datentypen. Die gebräuchlichsten sind:

- **Integer (`int`)**: Ganze Zahlen (z. B. `5`, `-10`, `42`).
- **Float (`float`)**: Dezimalzahlen (z. B. `3.14`, `-0.5`, `100.0`).
- **String (`str`)**: Text, der in Anführungszeichen eingeschlossen ist (z. B. `"Hallo"`, `'Python'`).
- **Boolean (`bool`)**: Wahrheitswerte (z. B. `True`, `False`).

**Beispiel:**
```python
x = 10          # Integer
y = 3.14        # Float
message = "Hi!" # String
is_active = False # Boolean
```

### Grundlegende Python-Syntax

Python hat eine klare und einfache Syntax. Einige wichtige Regeln sind:

- Verwenden Sie `=` zum Zuweisen von Werten zu Variablen.
- Verwenden Sie `print()` zur Ausgabe von Ergebnissen.
- Codeblöcke werden durch *Einrückung* (Leerzeichen oder Tabs) definiert, nicht durch Klammern oder Schlüsselwörter.
- Kommentare beginnen mit `#` und werden vom Computer ignoriert.

**Beispiel:**
```python
# Dies ist ein Kommentar
name = "Alice"  # Zuweisung eines Strings zu einer Variablen
print(name)     # Ausgabe des Wertes der Variablen
```

**Wichtige Punkte:**
- Einrückung ist entscheidend. Sie organisiert den Code visuell und stellt sicher, dass er korrekt ausgeführt wird.
- Verwenden Sie Kommentare, um Ihren Code zu erklären und verständlicher zu machen.
