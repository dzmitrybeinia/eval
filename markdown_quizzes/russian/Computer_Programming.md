### Что такое переменные?

**Переменная** — это контейнер, в котором хранится информация. Это как коробка, куда можно положить данные, чтобы использовать их позже.

**Основные свойства переменных:**
- У переменных есть названия (например, `x`, `результат`, `возраст`).
- Переменные могут хранить разные типы данных: числа, текст или значения типа "истина/ложь".
- Значение переменной может изменяться в процессе выполнения программы.

**Пример:**
```python
результат = 0  # Переменная "результат" хранит число 0.
результат = результат + 10  # Значение переменной "результат" обновляется до 10.
```

### Что такое циклы?

**Цикл** — это структура программирования, которая позволяет повторять набор инструкций несколько раз. Это экономит время и снижает вероятность ошибок.

**Типы циклов:**
1. **Цикл for** — используется, когда известно количество повторений.
2. **Цикл while** — используется, когда нужно повторять действие, пока выполняется условие.

**Пример:**
```python
# Цикл for, повторяющийся 5 раз
for i in range(5):
    print("Привет!")
```

### Условные конструкции

**Условные конструкции** позволяют программе принимать решения на основе определённых условий. Эти условия оцениваются как "истина" или "ложь".

**Ключевые слова:**
- `if`: проверяет, выполнено ли условие.
- `else`: выполняется, если условие не выполнено.
- `elif`: проверяет дополнительное условие, если первое не выполнено.

**Пример:**
```python
температура = 75

if температура > 85:
    print("На улице жарко!")
elif температура < 60:
    print("На улице холодно!")
else:
    print("Погода приятная.")
```

### Как всё это работает вместе?

Когда мы пишем алгоритмы, переменные, циклы и условные конструкции часто используются вместе для решения сложных задач.

**Пример алгоритма:** Найти средний балл 5 студентов:
1. Использовать переменную для хранения общей суммы баллов.
2. Использовать цикл для добавления баллов каждого студента.
3. Использовать условную конструкцию для проверки, высок ли средний балл.

**Пример псевдокода:**
```
общий_балл = 0
for каждый студент в 5 студентах:
    общий_балл = общий_балл + балл_студента
средний_балл = общий_балл / 5

if средний_балл >= 60:
    print("Сдано")
else:
    print("Не сдано")
```

#### **Themes:**
- алгоритмы с переменными, циклами и условными конструкциями

## YesNo

**Statement:** В псевдокоде средний балл рассчитывается, используя только условные конструкции.

**Answer:** False

**Feedback:**
